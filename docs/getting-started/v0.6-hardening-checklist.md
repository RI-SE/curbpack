# v0.6 hardening checklist

Release-grade guardrail evidence before advancing the Action/examples pin beyond `@v0.5.2`.

## SME tabletop (required)

Run these scenarios locally or in a paired review session. Record outcomes in the PR or release notes.

| Scenario | Expected safe behavior | Pass |
|----------|------------------------|------|
| Forged Git Note (`user_touch=ssh-agent-signed`, no valid sig) | Buyer surfaces stay **UNSIGNED**; AttestDisplay never green from string alone | ☐ |
| Tampered `latest_failure.json` (green cache, red tree) | ContextPack re-validates; export not fake-green | ☐ |
| Cross-pack stale cache (`pack_id` mismatch) | ContextPack ignores cache; uses requested packs | ☐ |
| HEAD moved after cache write | Cache rejected unless `expected_parent_commit_sha` matches HEAD | ☐ |
| Symlink escape under repo root | SafeJoin / pathjail refuses | ☐ |
| `.Git/` path (case variant) | Refused by path jail | ☐ |
| `curbpack check --json --heal` | stdout is parse-safe JSON only (no markdown hints) | ☐ |
| Mirror drift (afelin vs RI-SE main) | `mirror-drift` workflow opens issue or passes | ☐ |
| Attest without `--allow-dirty` on dirty tree | OCC conflict; no silent bind | ☐ |

## Automated gates (required)

- [ ] `go test ./...` green on Linux, macOS, Windows CI matrix
- [ ] `go run ./cmd/curbpack check` green in this repo (dogfood)
- [ ] Golden tests pass (`internal/exportx/golden_test.go`); update with `-update` only when intentional
- [ ] Fuzz targets (`FuzzSafeJoin`, `FuzzTextForbidRegex`, `FuzzParseHPURLFragment`) pass CI short fuzz
- [ ] `redteam-pilot` required check green on merge PR
- [ ] Claim-safety script green (`scripts/claim-safety.sh`)

## Trust-surface freeze (required)

- [ ] No new pack ids without human pathway confirm
- [ ] Capsule `schema_version` bump documented when `state_hash` field order changes
- [ ] No weakening of cite-or-refuse / confirm-prose grounding
- [ ] MCP remains propose-only (no confirm/attest tools)

## Release promotion criteria

Advance pin/tag only when **all** tabletop rows and automated gates above are checked, with:

1. Link to green CI run on the release commit
2. Link to merged PR with adversarial test coverage summary
3. Human attestation that mirror sync (`./scripts/curb-sync.sh`) succeeded post-merge
4. Explicit note if `RI-SE/curbpack` org token could not be verified (mirror-drift workflow)

## Deferred / human-only blockers

- **RI-SE org SSO / token scope** — mirror-drift may fail until GitHub App or PAT can read `RI-SE/curbpack`; fix in org settings, not by skipping the workflow
- **Branch protection context names** — if required checks rename, update source repo ruleset to match `ci` job names (`test`, `redteam-pilot`, etc.)

_Not a conformity assessment. This checklist prepares evidence for human review._
