For builders

Install once. Check daily. Open the browser only when you mean to.

  1. Install with the checksum-verified script (macOS/Linux) from the README.
  2. cyberready doctor then cyberready demo — prints a one-pager path; add --open only if you want the OS to open it.
  3. In your product repo: cyberready init --packs house-policy then cyberready check.
  4. Before a review wave: prepare-release, then a human attest.

Agents: use the Cursor skill; never loop on demo to “show the page.” Link the static sample instead.

Write your own pack: see repo docs docs/write-your-own-pack.md.
