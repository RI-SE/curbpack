### Task 2 — Git verification and the object-failure rule

**Requirements:** VR-R02, VR-R03, VR-R04, VR-R05
**Files:** `common/signing.py`, `review/gitseal.py`, `tests/test_vr00_signature.py`
**Test first:** `.venv/bin/python -m unittest tests.test_vr00_signature.GitSignatureTest`. Expected RED: Git method, content mismatch, and `test_unsigned_without_object_or_git_signature` are not implemented.
**Validation:** Git is local only (`git log -1`, `%G?`, `%GS`, blob contents). No fetch. Trust is `%G?` = `G`. Do not use the object certificate map. The signer is `%GS`, never the author or committer. `version` is that commit id. The commit is the latest one that touches the object. An older signed commit does not count when a later commit touches it. A present `signed` block, valid or not, stays method `object` and Git is not consulted. Outcomes when no `signed` block is present:

| Situation | status | method | reason |
| --- | --- | --- | --- |
| No repository, no commit that touches the object, or `%G?` is `N` | `unsigned` | `none` | no applicable signature |
| `%G?` is not `G` | `invalid` | `git` | that Git status; not the author name |
| `%G?` is `G` and the current bytes differ | `invalid` | `git` | content mismatch |
| `%G?` is `G`, signer is `%GS`, and the current bytes match | `valid` | `git` | none required |

A Requirement matches when the worktree file equals `git show <commit>:<path>`. A Pack is not one blob. It matches when every file in the Task 1 complete-directory digest, including dotfiles, has the same digest bytes in that commit, including `pack.json` after the signature is cleared, and the commit has no extra file that digest includes. Do not use `pack_directory_digest` for that file set. `test_unsigned_without_object_or_git_signature` is required: no `signed` block and no applicable Git signature returns `unsigned` / `none`. The test covers both no repository and a commit whose `%G?` is `N`. A non-repository export returns that same result and does not raise.
**Stop if:** a test would require a networked keyserver.
