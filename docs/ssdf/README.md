# NIST SSDF evidence map

This directory will map the applicable practices in **NIST SP 800-218** to controls the repository actually implements. This README is **not a compliance claim**.

For each claimed practice, record: **practice ID → existing control → file/test or other verifiable evidence → gap / required work → verification date**.

Do not invent policies or claim controls are present until the fresh code, CI and actual development workflow have been inspected. Reuse `policies/` and real test evidence rather than restating the same rule here.
