# PE-04 — Show the selected Pack's sources

**Status:** Draft (not yet approved)  
**Epic:** [EP-01 Pack Editor](../EPIC.md)

**As a Pack author**, I want to open a Pack and see its registered sources so that I can work with them individually.

**Accept when:** The page clearly identifies the Pack, document and adapter; each registered source has a row with the relevant section/source identification, source URL when useful, and the existing **Extract** and **Edit** actions; opening a Pack changes no Requirements.
