### Selection rule (from PE11-R02, not a new policy)

Export uses `selected_copy(root, pack_id)` only. `pack_id` comes from the catalog document's adapter, the same chain as `_signature_mark`. If that returns None, the page refuses and names the pack id. Do not use the latest-stamp fallback in `_copy_rows` (`chosen = selected_name or stamps[-1]`). Do not export a `kind: published` selection. Do not call `ensure_default_selection` from the export route. Opening `/` may still select a default; that is existing home-page behavior and is not part of this story.

### Which files are Pack files (from the existing loader)

`load_pack_directory` treats `pack.json` plus every other `*.json` directly in that directory as the Pack. Extract diagnostics already live in the sibling `<timestamp>.work/` directory (`work_directory`), not inside the copy. Export copies only those direct `*.json` files, by `write_bytes`, then runs the existing validator on the temp copy before rename.

Use `validate_pack(..., sealed=False)` and `validate_requirement(..., published=False)` through `load_pack_directory`. Do not call `_require_publishable`. `published=True` requires a signature, an edition, and no `origin`, which would reject an unsigned or locally copied working set. The story allows both.

A `*.json` file inside the working copy that fails that validator rejects the whole export and leaves no destination residue. Do not skip it and do not invent a filename allowlist. Non-JSON files and child directories inside the copy are not Pack files and are not copied. If a test can only express PE11-R05 by putting diagnostic JSON inside the Pack directory, stop. That is the story's stop condition.
