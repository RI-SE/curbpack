# Curbcheck catalogue

The procedures are the copied suite files in [suites/](suites/). The manual procedures are in [docs/procedures/](docs/procedures/). `make test-curbcheck` reads those files.

A row whose copied procedure calls `curbpack` is printed as outside. It is not a pass. A manual row and a "To be specified" row are printed and are not a pass. EV-001 is the seven carried checks already run in that same command.
