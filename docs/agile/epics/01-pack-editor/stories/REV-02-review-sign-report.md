# REV-02 — Review and sign a report

**Epic:** [EP-01 Complete Functional Pilot](../EPIC.md)

**As a reviewer**, I want to record my review and sign the report, so that others can identify which results I examined and approved as a review record.

**Accept when:**

- The reviewer can inspect the underlying Check results and record review decisions before signing.
- The signed report is tied to the actual saved report content, and verification detects later changes.
- Re-running Checks does not overwrite an existing signed report or silently make it represent a new run.
- The UI distinguishes a report compiled from the latest run from a report compiled from an earlier run.
- Changing signed review content requires an explicit re-signing process; signing does not certify legal compliance.
