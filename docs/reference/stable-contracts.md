# Stable contracts

The output contracts are maintained in [Outputs](outputs.md):

- [Run result](outputs.md#run-result): repository snapshot, loaded Packs, Claim digests, and Check outcomes.
- [Review report](outputs.md#review-report): the copied run result, Requirements, Claims, signature appendix, and optional reviewer decision and signature.
- [Check-tool response](outputs.md#check-tool-response): the JSON returned by an individual Check executable.
- [Pack export and publication](outputs.md#pack-export-and-publication): current directory layouts and copied objects.

Paths and directory configuration are defined in [Workspace](workspace.md) §2–§3. CLI arguments, terminal output, and exit codes are defined in [curbcheck](curbcheck-cli.md). Pack, Requirement, Claim, Check, and signature objects are defined in [Packs v2](packs2.md).

This page is an index; it does not maintain a second copy of the output schemas.
