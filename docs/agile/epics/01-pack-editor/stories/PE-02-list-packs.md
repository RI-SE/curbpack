# PE-02 — List Packs

**Status:** Draft (not yet approved)

**As a Pack author**, I want to see the Packs I work with so that I can open the right one.

**Accept when:** Each Pack has one row with its name, official document name and adapter; **Edit** opens that Pack; a Pack's sources are not mixed with another Pack's sources.
