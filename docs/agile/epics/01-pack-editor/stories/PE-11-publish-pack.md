# PE-11 — Publish a Pack

**Status:** Draft (not yet approved)  
**Epic:** [EP-01 Pack Editor](../EPIC.md)

**As a Pack publisher**, I want to publish the Requirements belonging to my Pack so that others can use a known, versioned release.

**Accept when:** Publication is a **Pack-level** action, not a source-row action; the published Pack contains the intended reviewed Requirements with matching `pack_id`; required signatures and the Pack seal verify; the publisher chooses `pack.version`; a published version is not silently overwritten; later editing or re-extraction leaves the published version unchanged.
