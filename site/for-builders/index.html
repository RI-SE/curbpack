For builders

Install, init, and check—green gates in your repo in under ten minutes.

Not conformity assessment. Not CE marking. Not a notified-body opinion.

Pick one of three ways in:

Write then check

Assistant proposes A and B → you pick → cite-check → you confirm (TTY or --i-am-human) → check.

curl -fsSL https://raw.githubusercontent.com/afelin/cyberready/main/scripts/install.sh | sh
cd /path/to/your/product
cyberready init
cyberready pathway status
# optional: cyberready research  → dual drafts → cite-check
cyberready check

Default pack is house-policy. Optional warm-start suggests checklists; drafts never replace check. Pin @v0.4.3.

Bring docs then check

cd /path/to/your/product
cyberready init
# place existing policies on pack paths, e.g.:
#   SECURITY.md
#   .well-known/security.txt
cyberready check

No portal PDF ingest — files in the repo only. Names above match the house-policy pack.
