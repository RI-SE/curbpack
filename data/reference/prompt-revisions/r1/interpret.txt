Propose Packs v2 Requirement fields for each provision. Use only what that provision's own law_text supports.

Provisions (JSON array). Each object has locus and law_text:
---
{provisions}
---

For each provision return one object with:
- locus: exactly the input locus
- id: a stable Requirement id, unique in this reply, named for the obligation. Not a claim slug.
- locator: the address inside the instrument, never the bare locus. An annex point is the annex roman numeral, a dot, and the locus. Points that list the content of the technical documentation are Annex VII, so locus 1(a) is VII.1(a) and locus 3 is VII.3. An article paragraph keeps its article number, such as 13(8).
- applicability: one string that copies the where-condition written in this law_text, including a where-clause in the middle of a sentence. Omit the key when there is none. "Where applicable" belongs here. If the same sentence limits when the artefact is required, keep that limit in this string. Do not turn the limit into a separate duty.
- strength: MUST, SHOULD, or MAY when this law_text contains shall, should, or may anywhere, including in a later sentence. One shall is strength MUST. A noun-phrase opening does not cancel a later shall. Omit strength only when none of those words appear. "Where applicable" is not MAY.
- responsible: one string, only the party this law_text names as holding the duty. Omit otherwise. Do not invent a manufacturer, operator, or authority. A body that only receives or requests material is not responsible.

Rules:
- Do not emit scope, exceptions, or note. Do not restate law_text in another field.
- One object per input locus. Do not invent, drop, or duplicate loci.
- Do not copy a duty from the annex introduction or from another provision.
- Do not include note, claim, search, law_text, signed, or origin.
- Do not return a bare array. Reply with only one JSON object and one result for every input locus. The row below shows the shape, not the whole reply:
  {"provisions":[{"locus":"3","id":"CRA-ANNEX-VII-RISK","locator":"VII.3"}]}
