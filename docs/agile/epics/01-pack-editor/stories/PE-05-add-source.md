# PE-05 — Add a source/section

**Status:** Draft (not yet approved)  
**Epic:** [EP-01 Pack Editor](../EPIC.md)

**As a Pack author**, I want to add a source within the selected document so that the extractor can process its relevant section(s).

**Accept when:** The document and adapter are taken from the selected Pack; I can add a source using the section/reference and URL needed by the adapter; it appears in the correct Pack; nothing is extracted automatically. Source metadata remains visible and available to extraction. The existing source/section configuration flow should be retained until its precise semantics have been verified.
