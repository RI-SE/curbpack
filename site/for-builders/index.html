For builders

Install, init, and check—green gates in your repo in under ten minutes.

Not conformity assessment. Not CE marking. Not a notified-body opinion.

Pick exactly one first move:

1. Safe try

curl -fsSL https://raw.githubusercontent.com/afelin/cyberready/main/scripts/install.sh | sh
cyberready doctor
cyberready demo

demo prints a one-pager path. Add --open only if you want the OS to open it. Pin @v0.4.3.

2. Product repo

cd /path/to/your/product
cyberready init
cyberready check

Default pack is house-policy. Before a review wave: prepare-release, then a human attest.

3. CI

- uses: afelin/cyberready@v0.4.3
  with:
    heal: "true"

Drop-in example: repo examples/workflows/cyberready-check.yml.

Recipes: 60-second paths. Sample without demo: buyer one-pager.

Works with assistants — run the CLI, then cyberready export --context-pack. Optional thin MCP: repo examples/mcp. Contract: docs/assistant-loop.md.
