# Sample review-pack (teaching)

Minimal **curbpack-native** review-pack for offline document triage demos.

```bash
curbpack review path/to/this/folder
```

Triage reports **confirmed** / **unconfirmed** / **contradicted** findings about the received document — not a product verdict, not conformity assessment, not CE / notified-body approval.

Required layers (v1): `01-gate-failures.json`, `02-action-report.md`, `03-executive-summary.md`, `buyer-onepager.html`.
