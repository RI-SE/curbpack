**Status:** Reviewed 2026-10-28 by danielfl.

**Epic:** [EP-01 Pack Editor](../EPIC.md)

**As a Pack author**, I want to add a Pack for a regulatory document so that I can start working with its sections.

**Accept when:** I can enter a Pack name, official document name and document URL and select an available adapter; saving adds the Pack to the list; saving does not extract or publish Requirements. A Pack corresponds to one document and its chosen adapter in the editor.
