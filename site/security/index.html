Security model

What you can trust — and what unsigned does not mean.

Not conformity assessment. Not CE marking. Not a notified-body opinion.

  • Install checksums: release downloads verify checksums.txt (sha256, fail-closed) in both install.sh and the GitHub Action.
  • Unsigned vs signed: unsigned capsules are labeled unsigned. Fake agent-bind tokens are never treated as verified signatures. Unsigned ≠ verified.
  • Offline packs: daily check needs no network. Network pack update requires a sha256 pin; otherwise stay offline / import locally.
  • Optional socket: integrator IPC uses a private path (mode 0600), not a shared world-writable /tmp default. Continues if unused.
  • Regex limits: pack patterns are length-capped and time-bounded to reduce regular expression denial-of-service (ReDoS) risk.

Full write-up: docs/security-model.md. Co-promotion / RISE-neutral language: docs/promotion-firewall.md. Report vulnerabilities via SECURITY.md.
