## Decisions recorded for this plan

These follow the story text. They are the contract this plan implements.

- `namespace_base` is required. A blank string fails. The created file uses `RISE`, the publisher named in the story and the reference-pack migration. The dialog shows the field and can save another non-empty value.
- A Pack and a Requirement require `namespace` as a non-empty string. Validation does not rewrite a namespace that is already present, and it does not check that the string equals `namespace_base` plus the name. That comparison belongs to VL-01.
- A new Pack built by this codebase sets `namespace` to `namespace_base + "/" + name`. `draft_pack` and other constructors that have no repository use `RISE` as `namespace_base`. Extract uses the open repository's `namespace_base` when `curbpack.json` is present.
- A new Requirement built by this codebase copies its Pack's `namespace`. `load_pack_directory` rejects a Requirement whose `namespace` is not exactly the Pack's `namespace`.
- `status` is `draft` or `reviewed`. `assurance_class` is an unknown field. A missing `status` is stored on the validated object as `draft`. Validation does not read the signature to choose the status, and signing does not write `status`.
- Pack `status` is not copied onto Requirements.
- `origin` stays optional. Absent stays absent. Present keys are `namespace` (optional non-empty string), `pack` (required pack id), `version` (required source version), and `requirement` (optional non-empty requirement id). A Pack origin omits `requirement`. An origin that only has `pack` and `version` remains valid. Do not add a namespace or a requirement id to an origin that does not already carry them, except when `working_copy` or `accept_published_version` creates a new origin from a source object that has those values.
- Identity is a tuple, not a new stored field and not a new directory. Pack identity is `(namespace, id)`. Requirement identity is `(namespace, pack_id, id)`. `version` stays a separate release fact.
- `reference-product/external_testing/curbpack/` is outside this checkout. Do not create it. Migrate the in-repo fixtures under `docs/reference/test-packs/` and `data/reference/`.
